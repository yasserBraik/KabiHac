# 💻 GDSC Al Yamamah — Student Projects Showcase

Welcome to our official project showcase! All participating teams can submit their projects and presentation details here via Pull Request.

---

## ⚠️ Project Hosting Requirement (Important)

All submitted projects **must be hosted using free GitHub project domains** (via **GitHub Pages**: `username.github.io/project-name`). Paid external domains are not required or accepted for this showcase—please make sure your live demo link is deployed and publicly accessible on GitHub before submitting.

### 🌐 How to Deploy on a Free GitHub Domain (GitHub Pages)
1. **Create a public repository** on your personal GitHub account and upload your project files (make sure your main landing page is named `index.html`).
2. Open your repository and click the **Settings** tab at the top.
3. In the left sidebar, click **Pages** (under *Code and automation*).
4. Under **Build and deployment -> Branch**, select **`main`** (and `/ (root)`), then click **Save**.
5. Wait 1–2 minutes and refresh the page—your free live project URL (`https://username.github.io/project-name`) will appear at the top!

---

## 🚀 How to Submit Your Team (3 Steps)

1. **Fork this repository:** Click the **Fork** button at the top right of this page to create your own copy.
2. **Add your team to the table below:** Edit this `README.md` file and add a new row with your **Team Name**, **Members' Names** (linked to your GitHub profiles and free GitHub project domain), and **Presenting Time**.
3. **Open a Pull Request:** Go back to your forked repository, click **Contribute -> Open pull request**, and submit it for review.
